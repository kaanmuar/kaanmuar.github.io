A content security policy, a security.txt, DMARC, and Core Web Vitals that pass for real visitors. But its HSTS max-age is 604800 seconds, seven days, so a browser that stays away a week forgets to insist on https.

Lesson: Raise HSTS max-age to at least a year, 31536000 seconds. Short values protect only frequent visitors.
