HSTS is sent with preload, every image analyzed has alt text, and language versions link back to each other. But the sitemap lists 878 community.wmo.int URLs, and search engines skip sitemap URLs from another host.

Lesson: Keep each sitemap to its own host. Give each subdomain its own sitemap, named in that subdomain's robots.txt.
