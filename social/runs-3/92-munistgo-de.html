Framing denied outright, a WordPress sitemap, language alternates that link back, and Secure cookies. But the search field's only name is its placeholder, so screen readers announce an unnamed edit box.

Lesson: Add a visible <label> or an aria-label to every input. A placeholder is a hint, not a name.
