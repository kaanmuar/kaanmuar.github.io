Suomi.fi mantém o HSTS por apenas uma semana.

Uma content security policy, um security.txt, DMARC e Core Web Vitals que passam para visitantes reais. Mas o max-age do HSTS é de 604800 segundos, sete dias, então um navegador que fica uma semana sem visitar esquece de exigir https. A lição para toda equipe: Aumente o max-age do HSTS para pelo menos um ano, 31536000 segundos. Valores curtos protegem só quem visita com frequência. A content security policy, a security.txt, DMARC, and Core Web Vitals that pass for real visitors. But its HSTS max-age is 604800 seconds, seven days, so a browser that stays away a week forgets to insist on https.

Lesson: Raise HSTS max-age to at least a year, 31536000 seconds. Short values protect only frequent visitors.
