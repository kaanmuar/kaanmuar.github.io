Fehlende Seiten bei CABEI antworten mit 200, nicht 404.

HSTS gilt ein volles Jahr, DMARC wird durchgesetzt, Framing ist begrenzt und jedes Bild hat Alt-Text. Doch eine erfundene Adresse antwortet mit 200 statt 404, also können Crawler Fehlerseiten als echte indexieren. Die Lektion für jedes Team: Liefern Sie für unbekannte Pfade einen echten 404-Status mit hilfreicher Seite, damit Suchmaschinen tote URLs entfernen. HSTS runs a full year, DMARC is enforced, framing is limited, and every image has alt text. But a made-up address answers 200 instead of 404, so crawlers can index error pages as real ones.

Lesson: Return a real 404 status for unknown paths, with a helpful page, so search engines drop dead URLs.

One automated analysis of public pages on 21 Oct 2026. A starting point, not a verdict.
