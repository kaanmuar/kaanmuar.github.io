FIDE: Einfaches http liefert die Website noch aus.

DMARC weist gefälschte Mails ab, die Sitemap liefert gültige URLs und der Text ist ohne JavaScript lesbar. Doch die Startseite über einfaches http antwortet mit 200, statt umzuleiten, und es wird kein HSTS-Header gesendet. Die Lektion für jedes Team: Leiten Sie jede http-Anfrage per 301 auf https um und ergänzen Sie dann Strict-Transport-Security. Eine automatisierte Analyse öffentlicher Seiten am 21. Okt. 2026. YouTube
DMARC rejects spoofed mail, the sitemap answers with valid URLs, and the text reads without JavaScript. But the plain-http home page answers 200 instead of redirecting, and no HSTS header is sent.

Lesson: Redirect every http request to https with a 301, then add Strict-Transport-Security.

One automated analysis of public pages on 21 Oct 2026. A starting point, not a verdict.
