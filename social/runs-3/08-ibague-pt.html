YouTube
One-year HSTS, a permanent https redirect, a meta description on every page analyzed, and the page text right in the HTML. But the search field has only a placeholder, so screen readers announce an unnamed box.

Lesson: Give every field a <label> or an aria-label. Placeholder text disappears on typing and is not a name.
