O Creative Commons passa para https com 302.

Um índice de sitemaps, páginas que declaram o idioma e robots meta que permite prévias grandes. Mas http:// chega ao https por um 302 temporário, e nenhuma página analisada envia Strict-Transport-Security. A lição para toda equipe: Use um 301 de http para https e depois adicione Strict-Transport-Security para os navegadores pularem o http na próxima vez.
