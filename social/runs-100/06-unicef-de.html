Preloaded HSTS, Organization JSON-LD, and five language versions linked to each other. But the search date filter on every page analyzed is named only by placeholder text, which vanishes as you type.

Lesson: Give every field a <label> or an aria-label. A placeholder is a hint, not a name, and it disappears on input.

One automated analysis of public pages on 19 Oct 2026. A starting point, not a verdict.
