GlossaireSécuritéFR

SRI : une empreinte pour les scripts empruntés.

Mot du jour : SRI : une empreinte pour les scripts empruntés. Subresource Integrity met un hash du fichier dans la balise. Si le CDN sert autre chose, le navigateur refuse de l'exécuter. Repérez-le : Listez les scripts que vous chargez depuis d'autres domaines. Ajoutez un hash d'intégrité à chacun de ceux qui ont une version fixe.
