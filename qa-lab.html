The suite I run on this CV

The catalog runs in the browser you already have open, on a Mac, a Windows PC, or a phone. Chrome, Firefox, Edge, and Safari stay in the list even when those programs are not installed. Before a run, choose the browsers and the screen size. Playwright, Cypress, Robot, Selenium, WebdriverIO, and Appium each run as their own process when npm run lab:runners is up, and those processes bring their own browsers. A result from one is not copied into the others.
