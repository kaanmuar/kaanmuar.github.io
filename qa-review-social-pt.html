O 404 assombrado: a página sumiu, o servidor diz 200.

Uma página inexistente que responde 200 OK é um soft 404. Os buscadores podem indexar a página de erro, e monitores que só leem códigos de status nunca veem o link quebrado. Exorcize hoje: Abra um endereço inventado no seu site. A página deve responder 404 e oferecer um caminho de volta: um link para a home e uma caixa de busca. SérieSEOPT

A cadeia de redirecionamentos zumbi: ela sempre volta.

Um link antigo salta de http para https, depois para www e, por fim, para a barra final. Cada salto custa uma ida e volta ao servidor, e os crawlers podem desistir de uma cadeia longa antes de chegar à página. Exorcize hoje: Siga seus links antigos até o endereço final. Mande cada um direto para lá com um único redirecionamento e atualize os links que você controla.
