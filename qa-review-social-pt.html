GlossárioSEOPT

hreflang: a página certa para cada idioma.

Palavra do dia: hreflang, a página certa para cada idioma. Um atributo que diz aos buscadores para qual idioma ou região é cada versão de uma página, para que quem fala espanhol chegue à página em espanhol. Confira: Abra uma página traduzida e confira se ela aponta para todas as versões de idioma, inclusive ela mesma. O Google ignora links sem retorno. Mito ou verdadeSegurançaPT

Mito ou verdade: Mito: o cadeado significa que o site é seguro. O HTTPS criptografa o caminho entre o navegador e o servidor.
