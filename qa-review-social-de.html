GlossarPerformanceDE

INP: wie schnell die Seite auf einen Tipp reagiert.

Wort des Tages: INP: wie schnell die Seite auf einen Tipp reagiert. Interaction to Next Paint misst die Verzögerung von einem Klick, Tippen oder Tastendruck bis zum nächsten Bild auf dem Bildschirm. Sie hat im März 2024 First Input Delay als Core Web Vital abgelöst. Erkennen Sie es: Finden Sie den langsamsten Tipp auf Ihrer Seite, oft ein Menü oder ein Filter, und teilen Sie die lange Aufgabe dahinter auf.
