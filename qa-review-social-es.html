GlosarioSeguridadES

SRI: una huella para los scripts prestados.

Palabra del día: SRI: una huella para los scripts prestados. Subresource Integrity pone un hash del archivo en la etiqueta. Si la CDN llega a servir otra cosa, el navegador se niega a ejecutarla. Encuéntralo: Haz una lista de los scripts que cargas desde otros dominios. Añade un hash de integridad a cada uno que tenga una versión fija.
