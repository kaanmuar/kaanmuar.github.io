TrickPerformanceEN

Find the code your page never runs.

30-second trick: Find the code your page never runs. The Coverage panel in Chrome DevTools marks every byte of script and stylesheet as used or unused while you load and use the page. Try it now: Click through the page's main task, then sort by unused bytes. Split or defer the biggest file that stays mostly red. GlossarySEOEN

hreflang: the right page for each language.

Word of the day: hreflang: the right page for each language. An attribute that tells search engines which language or region each version of a page is for, so a Spanish speaker lands on the Spanish page. Spot it: Open one translated page and check that it links to every language version, itself included. Google ignores links that are not returned. Myth vs factSecurityEN▶ FR

Myth: the padlock means the site is secure.

Myth vs fact: Myth: the padlock means the site is secure. HTTPS encrypts the trip between the browser and the server. It says nothing about the page's scripts, headers and cookies, or about who is behind the site. Check it: Check what the padlock does not cover: response headers, cookie flags, outdated scripts and a DMARC record.
