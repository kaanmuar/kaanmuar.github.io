What a review is
A public read, and a list of cases
QA-lab URL Review fetches a public https address, describes the response, and proposes test cases. It does not run those cases, sign in, submit forms, or generate load.
Frameworks and tools
Playwright, Cypress, Robot, Selenium, WebdriverIO, Appium, JMeter, and Gatling are the frameworks. axe-core, Lighthouse, k6, BrowserStack, Applitools, Percy, Provar, and Copado are named when they apply. None of them are launched.
Playwright and Cypress cases
It proposes test cases from one public https address and names each case for the framework your team uses: Playwright, Cypress, Robot, Selenium, WebdriverIO, Appium, JMeter, or Gatling. It does not write or run the scripts.
Your site
It only reads public pages. It does not sign in, submit forms, or generate load, and it does not run the cases it proposes.
How far it reads
The included first read covers twenty pages, two links deep. A wider read is priced on the page.
Where cases go
Excel, TestRail, Xray, Zephyr Scale, Jira, Azure Test Plans, MantisBT, JSON, plain text, or PDF. Case export is priced on the page.
Language
The page is written in English and can be read in Spanish, Portuguese, German, French, and Italian. The news strip follows the country of the connection and the language of the page.
Rules
A review reads a public page, describes the response, and proposes cases. The disclaimers state those rules, and the rules that apply in the country of the site under review. A lawyer has not reviewed them.
Elsewhere
Films and notes on YouTube, TikTok, X, LinkedIn, DEV, and Reddit.
